需求说明 — 货道合并（APP 独立页面）v1.2-APP 下载需求说明
一、页面定位
  • 独立页面：货道合并不再作为「货道管理」页的功能 Tab，而是机器详情下的独立入口，拥有自己的顶部导航（标题「货道合并」）
  • 与货道映射的关系：两者是先后关系而非同页 Tab——先完成货道映射（物号写入），再做货道合并；本页只读物号，不提供编辑（要改物号回货道映射页）
  • 用途：把多个左右相邻的货道并为一个出售单元，统一物号、统一扣减库存
  • 面向运营 / 运维人员；画框 375×812（逻辑像素）
二、页面结构
  • 顶部导航：返回 + 主页图标、标题「货道合并」、右上角温度（例：-8℃）——无功能 Tab 行
  • 柜体 Tab：主柜（默认）/ 副柜1，蓝 #378ADD 选中态；切柜清空选择；Tab 旁不显示数量/角标
  • 工具栏（常显）：合并货道（进入选择模式，on 态蓝底）、取消合并（进入拆组选择，on 态蓝底）、右侧「已合并 N 组」
  • 货道矩阵：上=软号（灰、只读）、下=物号（蓝、只读）；主柜 8×10 = 80 货道，副柜1 6×10 = 60 货道
  • 行头：每行一个上下两段小矩形——上「软」（灰底 #ECECEF / 灰字 #8E8E93）、下「物」（浅蓝底 #E6F1FB / 蓝字 #378ADD），各 26px、圆角 6px、10px 加粗，与格子上软下物一一对应；不显示 A/B/C 字母，也不参与选择
  • 底部按钮：默认「保存」；进入选择模式后变为「取消」+「合并所选 (n)」/「取消合并所选 (n)」
  • 提示语（hint）随模式切换：normal=操作引导；merge=已选 N 个 + 相邻约束；unmerge=已选 N 组
  • 三个弹窗：合并确认 / 合并组详情 / 拆组确认
三、编号规则
编号公式主柜 8×10副柜1 6×10说明
软号行×10 + 列 + 1010 ~ 8910 ~ 69厂测默认，自动生成、只读
物号行×10 + 列 + 11 ~ 801 ~ 60来自货道映射页，本页只读；合并后组内统一为合并物号
行标A/B/C…A ~ HA ~ F行号从 0 起（A 层 = 行 0），列号 0~9；仅弹窗文案使用（如「A0 + A1 → 13」），行头不显示字母

进入本页时读取设备当前物号（等价于货道映射页保存后的值），软号在任何映射/合并类原型中均不可编辑。

四、合并规则（与小程序版一致）
  • 先选后合并：直接点击货道即进入选择模式并选中该货道（无需先点「合并货道」按钮），继续点击左右相邻货道可多选
  • 相邻约束：只能选择与已选货道左右相邻（同一行）的货道；点击不相邻货道 toast「只能选择左右相邻的货道进行合并」并拒绝选中
  • 同柜体约束：仅同一柜体内可合并（矩阵按柜体切换，天然满足）
  • 两两配对：所选货道需为偶数个，按行、列排序后自动两两配对；奇数个 toast「所选货道需为偶数个（两两合并）」
  • 统一物号：每组合并后保留奇数物号（如 12+13 → 13）；两个同为奇/同为偶时取左侧（列号小）
  • 不可合并的情形：物号为空（未映射）的货道 → toast「物号为空（未映射）的货道不可合并」；已在合并组内的货道 → toast「该货道已在合并组内，请先拆组」
  • 合并确认弹窗：展示每对「A0 + A1 → 物号」的配对结果，确认后生效
  • 全部取消选择后自动退出选择模式，回到默认态
五、拆组（取消合并）
  • 单组入口：默认态点击已合并格子 → 弹出合并组详情（包含货道 / 合并物号 / 货道数）→ 点「拆分组」
  • 批量入口：点「取消合并」进入拆组选择模式，可多选合并组 → 底部「取消合并所选 (n)」
  • 恢复原物号：拆组后各货道按 origHw 记录恢复为合并前原物号（不是默认值）；无记录时回退默认物号（行×10+列+1）
  • 拆空所有合并组也算有效修改，可正常保存（表达"删除合并"意图）
六、保存与推送
  • 点保存 → 与已保存快照比对；无修改时 toast「未做修改，可直接返回」并阻断
  • 有修改 → 直接提交并保存，不显示推送进度 / 成功 toast；失败时 toast 错误信息（如「设备离线，请稍后重试」）
  • 保存后停留当前页，不自动返回

八、验收标准
  • 页面为独立入口：导航标题「货道合并」，无功能 Tab 行
  • 主柜 8×10（软 10~89）、副柜1 6×10（软 10~69），双行上软下物
  • 行头为上「软」下「物」两个小矩形，与格子上下两段一一对齐，不显示 A/B/C 字母
  • 直接点货道进入选择模式；选不相邻货道被拒绝并 toast
  • 选 2 个相邻货道 → 底部按钮变「合并所选 (2)」，弹窗展示「A0 + A1 → 奇数物号」，确认后生成 1 个合并组（绿色，无货道数角标）
  • 奇数个选择被拦截；已合并货道再次合并被拦截；空物号货道不可合并
  • 点已合并格子 → 组详情 → 拆分组 → 恢复原物号（12 与 13 各回各自原值）
  • 「取消合并」模式可多选组批量拆分
  • 切柜 / 全部取消选择 → 退出选择模式并清空选中
  • 未做修改点保存 → toast「未做修改，可直接返回」；有修改 → 直接提交，不显示推送进度 / 成功 toast，失败时提示错误，保存后停留在当前页
  • 本页物号不可编辑（点击不弹输入框）
  • 弹窗文案继续使用行标定位（如「A0 + A1 → 13」）
九、已确认 / 最终说明
  • 入口位置：由业务 / 产品侧决定，原型页面本身只保证可被机器详情正确跳转进入
  • 合并仅限两两：已确认，仅支持左右相邻的两个货道合并为一组；不支持 3 个及以上货道合并
  • 物号为空不拦截入页：进入本页不做物号校验；仅当空物号货道被选入合并范围时 toast「物号为空（未映射）的货道不可合并」并拒绝选中
  • 合并后从原单数货道出货：合并后统一物号为原配对中的奇数物号（如 12 + 13 → 13），库存与出货由设备侧按统一物号处理，出货时从原单数（奇数物号）货道出货
  • 保存推送不需要 toast：有修改时直接提交保存，不显示推送进度 / 成功 toast；失败时 toast 错误信息
  • 副柜规则同副柜1：当前版本只展示副柜1（6×10=60）；后续如有副柜2+，Tab 横向扩展，规则与副柜1一致
