一、功能概述

将控制系统软件货道编号与硬件物理货道编号绑定，模板可复用以免逐台配置。

模板按柜体维度维护：一个映射模板对应一个柜体，推送按柜体粒度下发（弹簧机/格子机按行×列配置）。

二、列表页
  • 模板卡片：名称、描述（选填）、类型标签（统一灰）、规格、货道总数、软/物号范围
  • mini 矩阵：2D 矩阵展示软/物号（上下分排）；默认展示前 3 行，超过 3 行时折叠并提供「展开剩余 N 层」按钮，与列数对齐
  • 映射模式：自动标注 1:1同号 / 顺序递增 / 自定义映射
  • 操作按钮：编辑/复制/删除（等宽），点击追加编辑页或弹确认框
  • 编辑流程：点编辑→右侧加编辑页（预填数据）→保存→返回列表
  • 复制流程：点复制→确认弹窗→"去编辑"→预填数据，名称加"副本"后缀→保存才建新模板
  • 删除流程：点删除→确认弹窗→确认后移除
  • 新增入口：底部"＋新增"→右侧加空表单（默认弹簧机，层/列为空）
  • 空状态：无模板时显示空状态引导
三、新增/编辑页
  • 设计原则：编辑页与新增页交互一致，仅标题改"编辑映射模板"并预填数据；按钮同为"取消+保存"
  • 基础信息：名称（必填）、描述（选填）、类型（弹簧机/格子机二选一，默认弹簧机）
  • 柜体维度：映射模板与柜体一一对应（单柜体），不涉及主/副柜组合；模板即单柜映射，推送时按柜体下发
  • 规格 — 弹簧/格子机：起始编号 10/11；层数(1~10)+列数（起始编号10→最多10列，11→最多9列），每层货道数可微调且同受该上限约束；软号 = 起始编号 + 行×10 + 列、物号 = 1 + 行×10 + 列（均与每层货道数无关，行×10 是硬规则），如选10→A行 软10~14/物1~5（5货道）、B行 软20~29/物11~20（10货道，A行不满不影响B行从20/11起算）；实时显示总数
  • 映射关系表：每层一行；无顶部列号头；每格是上下两个独立的圆角矩形、中间留缝——上矩形=软号（蓝字白底，自动生成·只读）/ 下矩形=物号（橙字，可逐格编辑）；1:1 同号时两个矩形都置灰；软号在任何情况下都不可编辑、不变色；点行头选整层（toggle），支持全选/清空；选中高亮只落物号矩形（蓝边+浅蓝底）
  • 行头：每层行头为上下两个米黄小矩形「软」(蓝字)/「物」(橙字)，不带字母，与格子同构同高；点行头整层 toggle，按压反馈只落「物」
  • 批量操作：选中单元格可「1:1同号」「+1」「-1」批量调物号；「+1/-1」触发同层后续自动递增（取该层最靠后的选中格为基准），「1:1同号」不触发递增，仅改选中格
  • 物号独立：每个单元格物号默认按 1+行×10 生成，可逐个编辑成自定义映射
  • 同层自动递增（本次新增）：修改某一层某货道的物号为 n 后，该层后续货道自动按 n+1、n+2… 递增；只影响当前层，不跨层修改，前面货道与其他层保持原值不变
  • 保存校验：①名称非空 ②名称不重复 ③弹簧/格子机：层/列/每层货道数≥1
  • 返回：点返回或"取消"关闭编辑页（不保存）
