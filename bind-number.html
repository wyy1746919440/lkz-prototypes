需求说明 — 编号绑定（设备注册流程） 下载需求说明
一、目标

降低工厂人员配置货道映射的成本；支持注册时选模板路径，并可一键推送设备生效。

二、设备注册流程
  • 步骤：SN → 机型 → 货道配置 → 按柜体选择映射模板（每柜可跳过） → 确认注册 → 操作成功
  • 步骤3 布局：按设备柜体逐柜展示（主柜 / 副柜1…），每个柜体独立选择或跳过；底部提供「不使用模板直接注册」
  • 未选柜：显示柜体规格 + 「选择货道映射模板 ›」+「不使用模板」（按默认映射生效）
  • 已选柜：展示模板名称 + 更换入口 + 映射模式标签 + 规格/货道数 + 全量点阵（每层独立成行，全部货道逐行展示，不折叠）
  • 跳过规则（不使用模板 ≠ 空映射）：任意柜体可不选模板直接注册；此时该柜体按系统默认映射生效 — 软号 = 起始编号 + 行×10 + 列，物号 = 默认物号 = 1 + 行×10 + 列，不存在"映射为空/待配置"的状态；提示文案："不使用模板 · 按默认映射生效，注册后可在机器详情中调整"
  • 确认注册：直接跳到「操作成功」页（注册流程第 4 步）：顶栏左「‹」返回（= 重新绑定）+ 中「操作成功」标题；白底居中 72px 绿圆 ✓ + 22px「操作成功」；浅灰底双按钮：「继续绑定」（白底橙边→回到第1步重置）/「设备检测」（橙底白字→自检页占位）
  • 注册进度：跳页同时顶部黄条 toast 显示注册/推送进度：先"正在注册设备…"，再依次追加"✓ 主柜映射已推送 / ✓ 副柜1映射已推送 / …"；已选模板的柜体逐个推送，未选模板的柜体沿用默认映射、不下发模板（汇总注明"×× 未选择模板，沿用默认映射"）；失败项停留 6 秒并附「重新推送」按钮
三、模板选择弹窗（注册侧）
  • 按柜体维度：映射模板为单柜体（一个模板 = 一个柜体的映射，无主/副柜组合模板）；弹窗标题随目标柜体变化：「为「主柜」选择映射模板」/「为「副柜1」选择映射模板」
  • 列表形式：卡片列表，只展示与目标柜体规格（层×列）匹配的单柜体模板
  • 卡片信息：模板名称 / 适用机型 / 规格（层×列·货道数）/ 映射规则 / mini 矩阵缩略图
  • 弹窗内 mini 矩阵：与「新增映射模板列表」一致 — 行号 A/B/C...（黄底）；每格上=软号(蓝)/下=物号(黄)，软=物时整格变灰；可横向滑动；> 3 层折叠"展开剩余 N 层"
  • 编号规则：与映射模板原型一致 — 软号 = 起始编号 + 行×10 + 列、物号 = 1 + 行×10 + 列（与每层货道数无关）
  • 搜索：弹窗顶部搜索框，按「回车」触发按名称模糊过滤；无匹配时显示「🔍 暂无匹配的模板」并提供「不使用模板」
  • 选择态：单选高亮（黄边框+浅黄底），再次点击同一张卡片可取消选中
  • 底部按钮：左侧"不使用模板"（该柜体跳过，按默认映射生效），右侧"确认选择"
四、推送设备流程（注册）
  • 触发：点"确认注册"直接进入注册/推送 loading，无二次确认弹窗
  • 按柜体推送：已选择模板的柜体逐个推送映射（主柜 → 副柜1 → …），每个柜体独立成功/失败；未选择模板的柜体沿用默认映射（不推送模板，只注册设备）
  • 流程：loading → 成功（绿✓）/ 失败（红✕+原因）
  • 失败原因：设备不可达 / 通讯异常 / 协议不支持
  • 重试：失败后提供"重新推送"按钮，直接重发
五、校验与权限
  • 默认映射兜底：任何情况下柜体都不会处于"无映射"状态 — 未选模板 → 默认映射（物号 = 1 + 行×10 + 列）；选了模板 → 按模板映射下发；后续可在机器详情 > 货道映射中调整
  • 弹窗只展示与目标柜体规格匹配的模板（层×列一致）
  • 支持注册时选模板（不依赖手动编辑）
  • 推送前校验设备可达性
  • 云端配置与设备配置状态分离
  • 注册/推送操作需记录操作日志
六、副柜（扩展柜）支持（注册侧）
  • 柜体结构：设备 = 主柜 + 1 副柜（副柜预置展示，不支持新增 / 删除）
  • 注册配置 — 双段卡：主柜、副柜1 各一张卡，结构一致：标题行（柜体名 + 右上「配置」按钮）+ 选择机型 块（机型卡片）+ 货道配置 块（层列 / 货道 / 三线·两线出货规则图例）；机型固定「弹簧机」，规格不允许改；副柜货道数锁死不可改，不提供 select/添加/删除入口
  • 模板结构：映射模板为单柜体（一个模板 = 一个柜体的映射），不再有「主柜+副柜」组合模板
  • 模板选择（注册侧）：按柜体逐个选择——先为主柜选模板，再为副柜选模板；弹窗只展示与该柜体规格匹配的模板；可跳过任意柜体（不选或只选一个均可），跳过的柜体按默认映射生效
  • 已选预览（注册侧）：步骤3 按每个柜体独立成块展示（主柜 / 副柜1…），已选块含模板名、规格、映射模式、全量点阵；未选块显示选择入口
