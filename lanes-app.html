一、页面定位

货道管理是机器详情「货道映射」入口跳转的独立页面，面向运营/运维人员，在矩阵上完成货道软号、物号的查看与物号编辑，并支持主副柜切换、批量改号、保存推送。

关联：货道合并已拆出为独立页面（见《货道合并-APP需求说明》v1.0-APP），本页只负责映射与检测，不再承载合并能力。

二、页面结构
  • 顶部导航：返回 + 主页图标、标题「货道管理」、右上角温度（例：-8℃）
  • Tab 区：货道映射（默认选中，蓝 #378ADD）/ 货道检测（占位空态）
  • 柜体 Tab（位于 Tab 区之下）：主柜（默认选中）/ 副柜1，蓝 #378ADD 选中态，仅在货道映射页内显示（货道检测页不显示）；各柜数据独立，切柜清空选中；Tab 旁不显示数量/修改角标
  • 批量操作条（固定置顶常显）：全选 / 清空 / 1:1同号 / +1 / −1 / 已选 N 个
  • 货道矩阵：行轴行头 A~（上下两段「软/物」，点行头选整层）；每格上下两个独立矩形——上=软号（灰、只读）、下=物号（蓝、可编辑）；主柜 8 层×10 列 = 80 货道，副柜1 6 层×10 列 = 60 货道
  • 底部保存：大圆角蓝按钮「保存」
三、编号规则
编号公式主柜 8×10副柜1 6×10说明
软号行×10 + 列 + 1010 ~ 8910 ~ 69厂测默认，自动生成、只读
物号（默认）行×10 + 列 + 11 ~ 801 ~ 60从 1 递增，可逐格编辑

行号从 0 起（A 层 = 行 0），列号 0~9；公式与柜体无关，按各柜层数取值范围不同。示例：主柜 A 层软 10~19/物 1~10、H 层软 80~89/物 71~80；副柜1 F 层软 60~69/物 51~60。各柜物号修改数据独立，切柜后各自保留。软号在任何货道映射类原型中均不可编辑。

四、交互规则
4.1 选中货道（批量前提）
  • 点击软号半格 → 选中/取消该货道（软号本身不编辑）
  • 点击行头 → 选中/取消整层；点「物」段只高亮物段，软段不变色
  • 点击「全选」全选当前柜体全部货道（再点取消）；「清空」将已选货道物号值清空（虚线空格态）并取消选中
  • 切柜清空：切换主柜/副柜1 时清空当前选中（选中按柜体维度）
4.2 单格编辑物号
  • 点物号半格 → 就地输入框；Enter / 失焦确认，Esc 取消
  • 校验：仅 1~999 正整数；非法（空/非数字/<1）toast「请输入 1~999 的物号」且不落值
  • 上限 999
4.3 同层自动递增
  • 某货道改值为 n → 同层右侧后续货道自动 n+1、n+2…（仅影响本层，不跨层）
  • 递增格同标修改态（黄底）
4.4 批量修改
  • 清空：将已选货道的物号值清空（虚线空格态）并取消选中；未选中时 toast「请先选择货道」
  • 1:1同号：已选物号恢复为默认（行×10+列+1），清空格一并恢复
  • +1 / −1：已选物号整体 ±1（下限 1）；空值格跳过，全部为空时 toast「已选货道物号为空，请先填写物号」
  • 未选中时点击 清空/1:1同号/+1/−1 → toast「请先选择货道」并阻断
  • 空值格可重新就地编辑填值（填 n 后同层右侧自动递增），或用 1:1同号 恢复默认
4.5 保存与推送
  • 点保存 → 按柜体粒度推送：统计全部柜体物号≠默认的格子数 → 提示「已保存并推送 2 个柜体（修改 N 处）」
  • 原型阶段为本地确认；真实推送需校验设备在线（离线提示「设备离线，请稍后重试」），复用既有推送进度/失败重试约定（按柜体依次回执）

六、待确认 / 待补充
  • 货道检测 Tab：当前仅占位空态，待业务侧提供检测交互（单个/整层/整柜、状态着色、结果展示）

七、验收标准
  • 柜体 Tab 位于功能 Tab 之下（仅货道映射页内显示），主柜/副柜1 可切换，默认主柜，选中蓝字蓝条
  • 主柜矩阵 8×10（软 10~89 / 物 1~80），副柜1 矩阵 6×10（软 10~69 / 物 1~60）
  • 各柜物号修改数据独立；切柜后选中清空（已选计数归 0）
  • 软号灰字只读、物号蓝字可编辑
  • 点物号半格就地编辑，Enter/失焦确认、Esc 取消，1~999 校验非法不落值
  • 改某格后同层右侧后续自动 +1 递增，仅影响本层不跨柜
  • 点软号/行头可选中，选中仅高亮物号半格，软号不变色
  • 清空：已选货道物号值清空（虚线空格态）并取消选中；空值格不参与 ±1，可重新编辑填值或 1:1同号 恢复
  • 物号≠默认时黄底标记修改态
  • 保存提示「已保存并推送 2 个柜体（修改 N 处）」
  • 货道检测 Tab 占位空态正常
