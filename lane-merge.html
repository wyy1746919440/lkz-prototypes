一、目标

机器详情补齐货道合并能力：支持将同柜体多个货道两两合并（默认保留奇数物号、统一库存），满足大容量商品陈列与多货道同时出货的场景；交互延续「货道映射」的矩阵操作语言，仅覆盖合并 / 拆分两个动作，不扩散到库存、模板等其他功能。

二、货道合并
  • 入口：机器详情 → 全部功能 → 货道合并（绿色 ⧉ 图标区分于映射）
  • 矩阵：沿用货道映射矩阵（A~J 层 × 0~9 列），格内显示物号（演示数据 11~110 递增，A0=11、J9=110）；已合并货道以绿色块 + 右上角货道数角标标识
  • 合并流程（先选后合并 · 两两配对）：在矩阵上直接点选货道进入选择模式（橙色选中框）→ 点选货道（仅左右相邻，支持一次多选多对）→ 底部出现「取消」+「合并所选 (N)」→ 点「合并所选」→ 确认弹窗列出每对的合并结果（默认保留奇数物号）→ 确认后生成多个两两合并组；工具栏「合并货道」仅作辅助入口，主入口为直接点选
  • 相邻约束：只能选择与已选货道左右相邻（同一行）的货道继续合并；点击不相邻货道时 toast 提示「只能选择左右相邻的货道进行合并」并拒绝选中
  • 两两合并：合并时按所选顺序自动两两配对（如 A 行选 11~20，合并为 11、13、15、17、19 五组）；所选货道数为奇数时提示「所选货道需为偶数个（两两合并）」；每组合并后默认保留奇数物号（如 12+13 → 13）
  • 拆分流程（支持多选批量）：点「取消合并」→ 可点选多个合并组（红色框多选）→ 底部「取消合并所选 (N)」→ 二次确认（列出将拆分的组）→ 批量拆分为独立货道并恢复原物号
  • 组详情：点击任意已合并货道 → 弹窗展示组内货道列表、合并物号、货道数，可直接发起拆组
  • 保存推送：点「保存」后推送设备生效；保存后停留在当前页，不自动返回（用户点左上角返回）；顶部黄条 toast 展示逐柜进度，失败可重试；未做任何修改时提示「未做修改，可直接返回」；未保存的合并/拆分修改在返回时丢弃
三、规则与边界
  • 合并仅限同柜体内的货道；切换柜体 Tab 后选择清空，各柜体合并独立编辑
  • 合并货道必须左右相邻（同一行内相邻）；不相邻选择被拒绝并 toast 提示
  • 合并只能两两配对（默认保留奇数物号），支持一次多选多对；所选数量必须为偶数
  • 物号为空（未映射）的货道不可参与合并；已在映射页被修改的物号直接沿用
  • 合并不改变映射关系：拆分后货道物号恢复为合并前各自的原物号
  • 合并组内货道库存统一扣减、出货时从组内任一货道出货（设备侧逻辑，本页仅配置关系）
四、异常与权限
  • 设备离线时阻断保存推送并 toast 提示
  • 权限点：lane_merge:view / edit / push
  • 进入 / 合并 / 拆分 / 保存推送 / 失败重试均需记录操作日志
五、本次修改内容（v1 → v2）

版本 v2.0（2026-10-10）｜第一～四章保留 v1 原文未改写，本次全部变更集中在本章。变更原因：小程序端矩阵形态对齐 APP 端。

一句话结论

矩阵由「单格只显示物号 + 顶部 0~9 列号头 + A~J 字母行头 + 合并角标」改为「每格上下两段（上软号只读 / 下物号）+ 无列号头 + 行头为「软」「物」两小矩形 + 无角标」。合并 / 拆组 / 保存等业务规则全部不变。
