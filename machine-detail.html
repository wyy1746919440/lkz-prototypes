需求说明 — 机器详情（货道映射 + 货道检测） 下载详细需求说明
一、目标

有屏机器详情补齐货道映射与货道检测两项能力，与无屏机器对齐；货道映射支持「选模板 → 本地预览 → 保存生效」，货道检测支持单个 / 整层 / 整柜并覆盖主柜副柜。

二、货道映射
  • 入口：机器详情 → 全部功能 → 货道映射
  • 柜体 Tab：主柜 / 副柜1… 各自独立矩阵；修改数量统一在工具栏右侧「已修改 N 项」展示，Tab 不显示角标、右上角不显示柜体总览
  • 矩阵展示（上软下物）：每格双行——上=软号（灰色，自动生成·只读，软号 = 起始编号 10 + 行×10 + 列）/ 下=物号（橙色，可编辑）；无 0~9 列号表头；左侧行头为上下两段「软」(灰)/「物」(橙)，与格子同构
  • 单格就地编辑：点击物号半格 → 变输入框（数字键盘），Enter/失焦确认、Esc 取消；输入 1~999；确认后同层后续货道自动递增（= 新值+1、+2…，只影响本层不跨层），递增格标修改态；物号 ≠ 默认物号时黄底（已修改）；空格点「+」可补填
  • 配置货道映射（模板应用）：工具栏「配置货道映射」打开模板选择弹窗（按当前柜体规格过滤模板，支持名称搜索、展开全部层预览）；点「应用」仅本地预览覆盖当前柜体映射，点「保存」后才推送生效；模板与柜体规格不一致时弹出警告，可取消或强制应用
  • 保存推送：点「保存」后才真正推送设备；按柜体逐个推送（主柜 → 副柜1 → …），顶部黄条 toast 展示逐柜进度，失败可重试；保存后停留当前货道映射页，不自动返回（用户手动点左上角返回）；「清空本柜」二次确认且仅清当前柜体
三、货道检测
  • 入口：机器详情 → 全部功能 → 货道检测
  • 检测维度：单个货道（点格子）/ 整层（点「检测整层」）/ 整柜（点「检测整机」）
  • 柜体支持：主柜、副柜均支持；切换 Tab 后矩阵与状态按新柜体刷新
  • 状态流转：检测中（黄色闪烁）→ 正常（绿）/ 故障（红/橙）；检测中格子禁止重复触发
  • 结果展示：底部实时显示选中货道编号与状态；超时（>15s 无回执）标记故障并 toast 提示
四、异常与权限
  • 设备离线时阻断推送 / 检测并 toast 提示
  • 模板不匹配：列表全展示、不完全匹配项带提示、应用前二次确认、支持强制应用
  • 权限点：lane_mapping:view / edit / push、lane_check:view / execute
  • 进入 / 应用模板 / 编辑 / 清空 / 保存推送 / 执行检测 / 失败重试均需记录操作日志
